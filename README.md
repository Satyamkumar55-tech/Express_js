# 🚀 Express.js Learning Repository

This repository documents my journey of learning backend development using **Express.js**.

The goal of this project is not to build a production-ready application, but to understand the core concepts behind backend development by implementing them step by step through small features and mini projects.

## 🎯 Objective

Learn how backend applications work by building REST APIs and understanding the complete request-response lifecycle.

Instead of following long tutorials, I focused on learning one concept at a time and immediately applying it by writing code.

* Express.js setup
* Creating an Express server

* Route parameters

* HTTP methods (GET, POST, PUT, DELETE)
* Request and Response objects
* Status codes

## 📈 My Learning Approach

For this repository, I followed a project-first learning approach:

1. Learn one concept.
2. Build a small feature using that concept.
3. Test it manually.
4. Refactor the code.
5. Move to the next concept.

This approach helped me understand *why* a concept is used instead of simply memorizing syntax.

## ▶️ Getting Started

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate to the project directory:

```bash
cd <project-folder>
```

Install dependencies:

```bash
npm install
```

Start the server:

```bash
node index.js
```

Or, if you're using Nodemon:

```bash
nodemon index.js
```
